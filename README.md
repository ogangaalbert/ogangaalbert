# Albert Oganga

Mechanical Engineering & Mathematics student at Alfred University, interested in building systems where hardware, computation, and experimental testing come together.

I enjoy taking an idea from a rough prototype to something measurable: wiring the hardware, writing the code, collecting data, finding what failed, and improving the design.

## What I'm working on

- **Servo-Driven Ultrasonic Mapping System** — Integrating an Arduino UNO, HC-SR04 sensor, and SG90 servo with C++ firmware and Python visualization. Current work focuses on calibration, repeatability, range error, and 2D environmental mapping.
- **Closed-Loop Smart Cooling Duct System** — Developing a sensor-controlled airflow system and testing its thermal response across different heat loads and damper configurations.
- **Computational Materials Research** — Using atomistic simulation, spectroscopy workflows, and data analysis to study structure–property relationships in glass and engineering materials.
